An offline guide and tracker for all 55 GTA 6 PS5 trophies, with a cited guide for every trophy, a roadmap to the Platinum, missable flags, and a spoiler setting. Progress is saved in the browser and can be exported and imported.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
